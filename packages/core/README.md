# carmen-core

Pure TypeScript core for [Carmen](https://github.com/antoniovazquezaraujo/carmen): the song model, the `.mr` parser/serializer and note generation, with no Angular or Tone dependency.

This package is primarily the runtime dependency of [`carmen-cli`](https://github.com/antoniovazquezaraujo/carmen/tree/develop/packages/compiler).
